# Task Manager App

A robust, full-stack task management application designed to help users organize their daily activities efficiently. It features user authentication, category-based filtering, priority sorting, and deadline tracking, all wrapped in a clean, responsive user interface.

## Features

- **User Authentication:** Secure registration and login system with session management.
- **CRUD Operations:** Create, read, update, and delete tasks seamlessly.
- **Advanced Filtering:** 
  - Filter tasks by category (**Work, Personal, Education**) via a custom interactive navbar dropdown.
  - Filter by status (**All, Active, Completed**).
- **Sorting & Priorities:** Sort tasks by closest/farthest deadlines or by priority levels (High, Medium, Low).
- **Smart Deadlines:** Visual indicators and badges for task deadlines (e.g., overdue, upcoming, safe).
- **Responsive UI:** A modern, clean interface built with Vanilla JavaScript, featuring toast notifications and dynamic DOM updates.

## 🛠️ Tech Stack

**Frontend:**
- HTML5 & CSS3
- Vanilla JavaScript (ES6+)
- Fetch API for asynchronous server requests

**Backend:**
- Node.js
- Express.js
- CORS & dotenv for environment management

**Database:**
- MongoDB
- Mongoose (Object Data Modeling)
